# DSA-Simple-Code

A collection of simple, beginner-friendly **Data Structures and Algorithms** implemented in **C++**. Each algorithm lives in its own folder with clean, easy-to-understand code and a dedicated `README.md` explaining the concept, sample input, and expected output.

This repository is meant to help students learn core DSA concepts through minimal, readable implementations.

## 🛠️ Language
All implementations are written in **C++ (100%)**.

## 🚀 How to Use
1. Navigate into any algorithm's folder.
2. Read its `README.md` for the definition, sample input, and expected output.
3. Compile and run the `.cpp` file:
```
   g++ filename.cpp -o output
   ./output
```
4. Provide the input as described in that folder's README.

## 📌 Topics Covered
- **Graph Algorithms:** Dijkstra, Bellman-Ford, Prim's MST, Kruskal's MST
- **Dynamic Programming:** 0/1 Knapsack, Longest Common Subsequence (LCS)
- **Sorting:** Merge Sort, Quick Sort
- **Trees:** Binary Search Tree (BST)
